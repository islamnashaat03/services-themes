# Arabic-first service website themes

First batch: law-firm, medical-clinic, creative-portfolio. Each is a real,
working bilingual showcase implementation, presented as authored demo work,
with no implication of paid client delivery, real professional registration,
or real appointments. Existing law/clinic design and assets are retained from
the workspace's template-library. Portfolio is a new, separately designed theme.

Each exports a standalone Arabic-default site, explicit /ar/ and /en/ routes,
locale content JSON, a versioned theme manifest, editable-content paths,
section order and theme tokens. Future Mawqi import is a planned adapter;
these themes are not registered in Mawqi yet. No platform code is changed.

Custom subdomain destination requested from user; awaiting their preference.
Until settled, prepare deployable static packages without changing live DNS.
Contact and appointment forms demonstrate local interactions without sending
data. Theme packages share no visitor state. All sample identities are fictional.
